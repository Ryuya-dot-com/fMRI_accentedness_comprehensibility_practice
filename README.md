# ジョイスティックによる評定の練習

スキャナー外で、練習用ジョイスティック（OTR-JOY-5など）を使う5段階評定課題です。HTMLとJavaScriptだけで動作します。参加者の結果ファイル・操作ログは作成せず、回答の送信、localStorage、IndexedDB、Cookie、アクセス解析は使いません。

課題別の公開URL：

- [外国語訛りの練習](https://ryuya-dot-com.github.io/fMRI_accentedness_comprehensibility_practice/?task=accentedness)
- [理解しやすさの練習](https://ryuya-dot-com.github.io/fMRI_accentedness_comprehensibility_practice/?task=comprehensibility)

各リンクでは、その課題だけで練習用10音声を各1回提示します。両課題を1回ずつ終えると、各音声を合計2回聞きます。従来の課題指定なしのURLでは、IDに応じた課題順で両課題を続けて実施します（10音声×2課題＝20提示）。

## 実施方法

1. 研究室PCに練習用Trainerとヘッドフォンを接続し、PCの音量を調整します。Gamepad APIに対応したPCブラウザーで公開URLを開きます。Chromeでのソフトウェア確認を実施していますが、実施機器での動作確認は別途必要です。
2. 実施する課題のリンクを開き、**本撮像と同じ参加者ID**を入力して「次へ」を押します。IDは提示順のフォーム・尺度方向（両課題連続時は課題順も）を決めるためだけに使い、保存・送信せず、条件決定後に入力欄を消去します。氏名は入力しません。別の課題を開く際も同じIDを入力します。
3. スティックを中央に戻し、人差し指のボタンを押して離します。左端へ倒して人差し指ボタン、中央へ戻す、右端へ倒して人差し指ボタン、中央へ戻す、の順に確認します。確認した軸・左右方向・ボタンは、このページを開いている間だけ保持します。
4. 指示を読み、人差し指ボタンで開始します。開いたリンクの課題を10音声で練習し、もう一方の課題には自動で進みません。音声中は操作せず、評定画面が出てから3秒以内に確定します。
5. 「練習は終了しました。」で終了です。「もう一度練習する」で最初からやり直せます。Esc、機器切断、別画面への移動、音声再生の停止があった場合は、その回を停止します。

## MRIとの対応

- 初期選択は3。中央から左右へ倒すたびに1段階動き、倒し続けても連続移動しません。次の移動には中央への復帰が必要です。傾きの量を評定位置へ直接対応させる方式ではありません。
- 中央判定と方向判定のためにアナログ軸を読みます。校正後の中央範囲は±0.15、移動閾値は±0.5で、現行MRI側の値を使用します。
- 確定は人差し指の新たな押下だけです。数字キー・矢印キー・マウスによる評定はありません。聴取中の操作と、評定開始時の倒しっぱなし・押しっぱなしを回答へ持ち越しません。初期値3を動かさず確定することは可能です。
- 確定後は選択を緑にし、3秒の評定画面を最後まで維持します。時間内に確定しなかった場合は未回答として次へ進み、練習用の短い案内を表示します。正解・不正解の判定はしません。
- Trainerの過去の実測では人差し指B0、MRI用932 R827ではB2でした。ブラウザーでも同じ番号になるとは仮定せず、開始時に実際に押した人差し指ボタンを選びます。MRI撮像パルスは使いません。
- 指示文は `メモ/Pre-rating task.docx` の日本語定義を反映したMRI側の現行説明から抽出しています。理解の正誤よりも理解の難しさの感覚、文法・語彙を含まない発音の訛り、2項目の評価が一致する必要はないことを説明します。見出しは「外国語訛り」、端点は同日の後続ユーザー指示により「理解しにくい／理解しやすい」「訛りが強い／訛りがない」とし、「とても」「まったく」を加えません。資料の1–100尺度と「自然さ」は導入しません。

## 音声・課題順・時間

2026-11-13、課題説明から「スティックを中央に戻し、ボタンから指を離してください。」を削除しました（`instruction_version=prerating_ja_v3`）。開始時の機器校正の案内と、中央復帰・押し直しの操作規則は維持しています。

ユーザーが公開利用を承認した、既存の練習専用10本のWAVを変更せずコピーしています。本撮像48文とは文IDが重複しないこと、コピー後のハッシュが元WAVと一致することを確認しています。音声の文面・話者情報は参加者画面に表示しません。

`practice.json` は現行Python実装の練習予定を元にした8種類の固定フォームです。ID 001–008を代表条件とし、009以降は8条件周期で選びます。任意の正の整数に対応し、001と1は同じ条件です。尺度X/Yと、両課題連続時の課題順はMRIと一致します。2026-11-13のユーザー指定により、Webでは各課題にP1・P2両方の練習音声を使います。本番の課題別文群割当てとは異なり、MRI側の刺激・予定は変更していません。**練習内の提示順と待機時間は8フォームごとの固定値であり、任意のID全体をseedに使うMRI本撮像の提示順を再現するものではありません。**

各課題は、従来その課題に割り当てていた5音声に、もう一方の5音声を続け、練習専用10音声を1回ずつ使用します。先頭はJapanese、同条件の3連続はありません。途中の5音声目で課題切替や休憩は入りません。課題の冒頭・末尾の固視は各10秒。WAV全長→評定前固視0–2.5秒→評定3秒→ITI 2–6秒で、待機は元の各音声のPython練習予定の値です。本撮像の9分撮像待機はありません。デジタル音量係数は現行設定の0.3ですが、PC・ヘッドフォンが異なるため耳元音量の一致を保証しません。

画面と音声はブラウザーで進めます。操作規則の一致と、MRI装置・耳元音声の物理同期精度は別です。このサイトはMRI本撮像の提示プログラムとしては使用しません。

回答は現在の試行の選択状態として一時保持するだけで、試行終了時に破棄します。課題の記録を保存しない仕様と、GitHub Pagesがサービス運用上のアクセス情報を扱うことは別です。

## 保守と検証

外部ライブラリ、ビルド、サーバー処理は不要です。GitHub Pagesの公開元は `main` ブランチのルートです。

```sh
node --test tests/*.test.mjs
python3 -m http.server 8766 --bind 127.0.0.1
```

元の研究プロジェクト内の配置でのみ、次の開発用コマンドを使えます。参加者のPCにはPythonは不要です。

```sh
PYTHONDONTWRITEBYTECODE=1 ../.venv/bin/python tools/prepare.py
PYTHONDONTWRITEBYTECODE=1 ../.venv/bin/python tests/compare_mri.py
```

`tools/prepare.py` は既存の練習音声と8フォームを抽出します。本撮像の音声・予定は変更しません。`tests/compare_mri.py` は実際のPythonとJavaScriptの選択処理を200系列・16,000回の更新で比較します。検証範囲は [verification.json](verification.json) に記載します。実機Trainerと研究室PCの組合せ、他OS・他ブラウザー、MRI物理入力・同期は未確認です。
